# خلية الإصغاء والتكفل بانشغالات المواطن — ولاية الوادي 🇩🇿

بوابة إلكترونية رسمية متطورة لتقديم وتتبع شكاوى وانشغالات المواطنين، مبنية بتقنيات الويب الحديثة، تهدف إلى تقريب الإدارة من المواطن وتسهيل عملية التكفل بالانشغالات عبر مسار رقمي شفاف وآمن.

## 🛠 التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** React 18, TypeScript, Vite
- **التصميم والتنسيق:** Tailwind CSS (مع خطوط "Changa" و "Tajawal" العربية)
- **الأيقونات والرسومات:** Lucide React, SVG Assets
- **الحركات التفاعلية:** Motion (Framer Motion)
- **التخزين المحلي (مؤقتاً):** LocalStorage Simulation (GrievanceService)

```text
src/
```

## 🚀 كيفية التشغيل محلياً (Development)

1. **تثبيت الاعتماديات:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   سيتم تشغيل الموقع محلياً على المنفذ `3000`.

3. **البناء للإنتاج:**
   ```bash
   npm run build
   ```

## 🔗 الانتقال إلى بيئة إنتاج حقيقية (Production API)

المشروع مصمم حالياً بطريقة **معزولة (Decoupled)** بحيث يمكن استبدال طبقة التخزين المحلي بسهولة دون التأثير على الواجهة.

للربط بقاعدة بيانات حقيقية (مثلاً: Supabase, Firebase, Node.js+PostgreSQL):
1. افتح ملف `src/services/grievanceService.ts`.
2. استبدل دوال `localStorage` بطلبات `fetch` أو `axios` إلى الـ API الخاص بك.
3. قم بإرجاع الوعود (Promises) وتحديث `GrievanceForm.tsx` لاستخدام `async/await`.

## 🛡 الأمان والموثوقية المدمجة حالياً

- **منع الإزعاج (Rate Limiting):** لا يمكن إرسال أكثر من عريضة واحدة كل دقيقتين من نفس المتصفح.
- **سياسة الخصوصية:** مدمجة وتتوافق مع القانون الجزائري 18-07 لحماية المعطيات الشخصية.

## ➕ إضافة بلدية أو تصنيف جديد
لإضافة تصنيف جديد أو بلدية جديدة:
1. افتح ملف `src/types.ts` وأضف القيمة إلى الـ Type (مثل `GrievanceCategory` أو `Municipality`).
2. افتح ملف `src/data.ts` وقم بإضافتها إلى المصفوفات الثابتة لتظهر تلقائياً في القوائم المنسدلة للنموذج.
