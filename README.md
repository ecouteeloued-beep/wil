# خلية الإصغاء والتكفل بانشغالات المواطن — ولاية الوادي

بوابة إلكترونية عربية لتقديم وتتبع انشغالات المواطنين، مع لوحة إدارة متعددة الأدوار ومصادقة Supabase Auth.

## التشغيل

```bash
npm install
npm run dev
npm run lint
npm run build
```

## إعداد Supabase

1. أنشئ مشروع Supabase واضبط `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
2. نفّذ `supabase/schema.sql` من SQL Editor.
3. أنشئ مستخدمي الإدارة من **Authentication → Users**.
4. استخدم `supabase/admin_accounts.sql` لربط حسابات Auth بجدول `public.users`.
5. استخدم `supabase/role_permissions.sql` لتطبيق صلاحيات الأدوار الحكومية الدقيقة.
6. استخدم `supabase/admin_management.sql` لتعديل الحسابات وإسناد الشكاوى وإضافة الردود.

## نموذج الصلاحيات

- **wali:** وصول شامل إلى الشكاوى والتقارير والمستخدمين واعتماد الردود.
- **super_admin:** إدارة تقنية ورقابة وقراءة الشكاوى دون رموز دخول ثابتة.
- **supervisor:** رقابة وتوجيه ومعالجة ضمن نطاق الخلية أو المصلحة واعتماد الردود المسموح بها.
- **head_department:** ملفات المصلحة المسندة إليه وإعداد الردود.
- **employee:** الملفات المسندة إليه فقط، مع القراءة والمعالجة وإعداد الرد دون اعتماد نهائي.

الصلاحيات مطبقة في قاعدة البيانات عبر Supabase RLS، وليست مجرد إخفاء أزرار في الواجهة.

## الأمان

- لا توجد كلمات مرور أو PIN ثابتة داخل المصدر.
- دخول الإدارة يتم عبر Supabase Auth.
- تتبع المواطن يتم عبر رقم التتبع ورقم الهاتف من خلال دالة مقيدة.
- القراءة والتعديل الإداريان محميان بسياسات RLS حسب الدور ونطاق الإسناد.
- البيانات الداخلية وسجل التدقيق غير متاحين للزوار.

لا تضع `service_role key` داخل الواجهة أو أي متغير بيئة يبدأ بـ `VITE_`.
